# 100-days-of-machine-learning
Machine Learning Engineer Learning Portfolio 

Welcome to my Machine Learning Engineering repository! This project tracks my daily progression from foundational data manipulation to production-grade ML, Deep Learning, and MLOps architectures. The curriculum and project scope are aligned directly with the official \*\*Google Cloud Professional Machine Learning Engineer (PMLE)\*\* 

Master Architecture: The 6 Core Engineering Domains ### 

1.Low-Code ML & Fast Baselines: Leveraging BigQuery ML, pre-trained APIs, and Retrieval-Augmented Generation (RAG) to establish fast performance benchmarks.
2.Data & Feature Engineering: Building clean data pipelines using SQL, Pandas, and Feature Stores to manage data without skew.
3.Custom Model Building & Hardware Acceleration: Training custom Scikit-Learn, PyTorch, and XGBoost models, with hyperparameter tuning and hardware selection (CPUs, GPUs, TPUs).
4.Serving & Scaling Online Inference: Packaging models into Docker containers, serving APIs via FastAPI, and setting up canary deployments.
5.Automating & Orchestrating MLOps Pipelines: Automating continuous training and deployment workflows using Kubeflow Pipelines and CI/CD triggers.
6.Monitoring, Safety & Responsible AI: Tracking data drift, auditing algorithmic fairness, and establishing LLM guardrails.
